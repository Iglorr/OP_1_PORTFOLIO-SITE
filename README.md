# Portfolio

## Frontend
Open `frontend/index.html` met een lokale webserver (bijvoorbeeld Live Server).

## Backend
ASP.NET Core Web API met .NET 10 en Minimal API.

Start vanuit de hoofdmap:

```powershell
dotnet run --project backend/coreApi
```

Swagger UI: http://localhost:5229/swagger

De backend bevat momenteel het standaard weatherforecast-endpoint. Projecten, blogposts en de database worden later toegevoegd.
